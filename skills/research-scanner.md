# Skill: research-scanner

## What
把"信息过载"切成三段：取舍 → 精读 → 摘要，不浪费时间在不重要的内容上。

## When to Use
- 收到一个 zip / 文件夹 / 一堆链接，任务是"从中提炼点东西出来"。
- 要翻译、要写综述、要做竞品对比。

## Input
- 原始资料路径或链接列表。
- 我最终要拿这个产出什么（交作业？自己学？写文章？）——用途决定取舍标准。

## Steps
1. **列清单**：把所有文件/链接列成一张表，标类型（PDF/视频/网页/代码）。
2. **打重要度标签**：高/中/低。判断标准只看一条——"这个跟我最终产出有没有直接关系"。
3. **只精读高标签**：中标签扫摘要，低标签不看。
4. **每份高标签资料写 3 行笔记**：核心观点 1、核心观点 2、我能用在哪。
5. **汇总成一张表**：观点 × 来源，作为下一步写作/翻译的原料。

## Tools
- Edge headless 抓网页
- Python 脚本批量读 PDF 目录（PyPDF2 / pdfplumber，按需装）
- 本仓库 L1_raw/（存原始笔记）

## Output
- 一张"资料 × 重要度 × 3 行笔记"的摘要表。
- 明确告诉我"哪些资料我决定不看"，并写一句理由。
