# Skill: weekly-planning

## What
用 15 分钟把下一周排好，不拍脑袋。

## When to Use
- 每周日晚 / 周一早。
- 连续两周感觉"忙了一周但不知道忙了啥"的时候。

## Input
- 本周必须交的硬 deadline（课程作业 / 项目节点 / 挑战提交）。
- 上周 usage_log / AAR 里未完成的任务。
- 本周天气 / 身体状态（读 L1_raw/日常_膝盖与身体状况.md）。

## Steps
1. **列硬 deadline**：把这周必须交的东西按日期排好。
2. **继承上周遗留**：上周没做完的事，能做就搬进这周，做不了就明确砍掉。
3. **固定块**：每天 30 分钟英语听力（四级备考）、高数弱项每周 3 个 1 小时块。
4. **身体约束注入**：不排跑步/跳绳；雨天骑车通勤改成公交；每个编程块后加 5 分钟起身。
5. **留 20% 缓冲**：不要把日程排满，突发事件来了才有空间。
6. 周日晚对照本周日历做一次"完成率"统计，写进下周的输入。

## Tools
- 本仓库 usage_log.md（读上周遗留）
- L1_raw/日常_膝盖与身体状况.md（身体约束）

## Output
- 一张本周日历块表（周一到周日，每格 1-2 行）。
- 一句"我这周主动砍掉了什么，为什么"。
