# Skill: blog-writer

## What
产出"人写出来的"中文文案，而不是"AI 味很重"的排比段。

## When to Use
- 任何要发给别人看的中文文字：公众号、小红书、朋友圈、情侣视频配文、课程群回复。

## Input
- 主题 / 目的（让人笑？让人买？让人理解一件事？）。
- 风格偏好（撒娇 / 诚恳 / 搞笑古风 / 高情商）。
- 长度限制。

## Steps
1. **先列 3 个必须出现的点**，其他都可以丢。
2. **写初稿**：不追求文采，把事说清就行。
3. **去 AI 味自检**：
   - 删掉所有"首先 / 其次 / 总而言之 / 在这个快节奏的时代"。
   - 删掉连续两句以上结构对仗的排比。
   - 至少加一个"我自己的真实小细节"（比如膝盖疼、被报错磨到炸毛）。
4. **口播一遍**：嘴里念出来卡壳的句子，重写。
5. 交付前读一遍 identity.md 第 5 条原则。

## Tools
- 豆包（生成初稿 + 改语气）
- 本仓库 L1_raw/日常_膝盖与身体状况.md（找"真实小细节"素材）

## Output
- 一段 ≤ 指定字数的成稿。
- 一句"我删了哪些 AI 味句子"的说明（可选）。
