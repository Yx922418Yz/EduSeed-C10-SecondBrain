# L1 原始笔记 — 书法主题 MaaS AI APP 项目

> 这个项目是我当竞赛队长带的队做的，我负责 Python 那一块。

## 项目是什么

- 给书法爱好者做的一个小程序：上传手写字 → AI 点评笔画结构 → 生成练习建议。
- 技术栈：前端小程序 + Spring Boot(队友写的) + MySQL + 我这边的 Python AI 服务。
- 代码托管在 Gitee，我个人 GitHub 上也有镜像。

## 我这边踩过的坑

1. **start.bat 启动脚本**：一开始我写了一堆相对路径，队友在他电脑上跑就报"系统找不到指定的路径"。后来改成 `cd /d %~dp0` 先切到脚本所在目录，再用相对路径，才好。
2. **MySQL 密码明文写在 config.py 里**：被学长看到骂了一顿，后来改成读环境变量 / .env 文件。
3. **Git 分支管理**：一开始所有人都往 main 上推，互相覆盖。后来强制每个人开自己的分支（feat/liyaxuan-xxx），合并前先 pull，才稳。
