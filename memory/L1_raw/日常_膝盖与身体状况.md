# L1 原始笔记 — 个人状态备忘

> 这些不是技术笔记，但 Agent 排计划时必须知道。

## 身体

- 双侧膝盖长期疼，针扎感，怕冷怕风，下雨天前必疼，夜里更明显。
- 所以：
  - 跑步 / 跳绳这类剧烈运动 → 默认不排进周计划，除非医生说可以。
  - 雨天 → 提醒带护膝、不要骑车通勤。
  - 久坐写代码 → 每 50 分钟站起来走两步，这个提醒要进 weekly-planning。

## 学习节奏

- 英语四级在备考，每天要留 30 分钟听力（精听选择题）。
- 数学（高数下：微积分 / 微分方程 / 级数）是弱项，每周至少 3 个 1 小时块。
- C 语言（数组 / 递归 / 水仙花数）作业要留时间写。

## 情绪

- 对"AI 味太重"的回复会直接炸毛——让 Agent 写任何对外文案前，先自检一遍"这话像不像豆包说的"。
- 被多轮报错磨到烦躁时，正确做法是停 5 分钟喝口水，不是继续硬改。
