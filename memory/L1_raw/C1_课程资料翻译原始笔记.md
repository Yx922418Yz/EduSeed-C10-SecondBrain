# L1 原始笔记 — C1 CS146S 课程资料获取与翻译

> 日期：2026 年上半年，C1 挑战期间随手记的原始素材，未经结构化。

## 当时发生了什么

- 拿到的材料是 CS146S_offline.zip，里面是一堆英文课程视频字幕 / PDF（Vibe_Coding_Playbook.pdf 之类）。
- 任务：把这些资料翻成中文，并且要"像人写的"，不能是机翻腔。
- 一开始我直接把整本 PDF 扔给 AI 让它翻，结果翻出来又长又干，导师说"太豆包了"。
- 后来改成：先自己读一遍目录，列出每章我认为最该保留的 3 个观点，再让 AI 只翻这 3 个观点的上下文，最后我自己用口语顺一遍。
- 效率反而比"全文机翻"高，导师那边一次过。

## 当时踩的坑

- 直接全文翻译 → 输出巨长、重点丢失 → 导师打回。
- 没有先做"取舍" → 把时间浪费在不重要的段落。
- 一开始不知道怎么把 zip 里的 PDF 批量导出来，对着文件管理器点了半小时。

## 灵光一现（后来变成技能的种子）

> "翻译 = 取舍 > 字面转换。先决定什么该翻，再决定怎么翻。"

这条后来被我提炼进 L3 的 research-scanner 技能里。
