## Â（Action Plan 行动计划）
1. 1. **列清单**：把所有文件/链接列成一张表，标类型（PDF/视频/网页/代码）。
2. 2. **打重要度标签**：高/中/低。判断标准只看一条——"这个跟我最终产出有没有直接关系"。
3. 3. **只精读高标签**：中标签扫摘要，低标签不看。
4. 4. **每份高标签资料写 3 行笔记**：核心观点 1、核心观点 2、我能用在哪。
5. 5. **汇总成一张表**：观点 × 来源，作为下一步写作/翻译的原料。
